Agent Workspace anatomy

A desktop terminal for running Claude Code, Copilot CLI and shells side by side in tabs, with each tab's agent status visible at a glance. This page names every part of the window, the code behind it, and what each part does.

Rust + GPUI alacritty_terminal 0.26 Windows first, then Linux No AI of its own

Status

Reading the status badge

The badge on a tab's icon is the same status used by the hover card, group totals and toasts. Ready for review means unread finished work, not that the work is correct.

BadgeMeaning
WorkingThe agent is on a turn. A Copilot tab also shows a turning ring before the title.
Needs attentionWaiting for permission, waiting for your reply, a bell, or a clipboard write to approve. A ▲ shows before the title.
Ready for reviewFinished while you were on another tab, until you select it (shown with a check).
IdleThe agent waits for your next prompt.
RunningA command typed at a bash, zsh or PowerShell prompt has run for over half a second. Pulses for 10 s.
Recent outputOutput arrived lately, with no reliable agent status.
ExitedThe program ended with an error. An agent that exits with 0 becomes a shell tab instead.
Under the hood

How the crates fit together

Only app depends on GPUI. Pure logic lives in workspace-model with unit tests. Agent hooks travel through agentws-hook over a local socket or pipe.

What it does

Major features

Tabs & groups

Organize many sessions

  • New tabs open below the selected one, in its folder
  • Groups, pins, colors, drag to reorder
  • Duplicate Ctrl+Shift+D, close Ctrl+Shift+W
  • Busy tabs ask before closing
Attention

Know who needs you

  • Status badges from the agents' own hooks
  • Toasts for background agent tabs
  • Jump to the next waiting tab Ctrl+Shift+A
  • Collapsed groups keep their counts
Terminal

A real terminal

  • Copy, paste, scrollback, mouse reporting
  • Search output Ctrl+Shift+F
  • Clickable URLs and path:line links
  • Clipboard writes from programs ask first
Command history

Commands you ran, anywhere

  • Inline suggestion, accept with Right
  • HISTORY popup on Up, with folders
  • Last command offered after a restart
  • bash, zsh and PowerShell
Files

Explorer and viewer

  • Tree follows the tab's folder, dims ignored files
  • New, rename, delete, open a tab there
  • Markdown, JSON, SVG rendered; images
  • Edit and save, reloads on disk changes
Settings & persistence

Comes back as you left it

  • Window, tabs, groups and order restored
  • Settings page, applied live, search and reset
  • Hand-editable settings.json, shortcuts too
  • Light theme, font, opacity and blur
